# Linkovia Network

Site web de [Linkovia Network](https://linkovia-network.org), une association qui agit dans le développement local et la coopération internationale.

## Stack

HTML / CSS / JavaScript vanilla — aucune dépendance, aucun build.

- Globe 3D interactif : [Globe.gl](https://globe.gl/) via CDN
- Internationalisation : FR / EN via `i18n.js`
- Hébergement : GitHub Pages sur le domaine `linkovia-network.org`

## Lancer le site en local

Double-clic sur `index.html` dans le navigateur. Aucune installation requise.

## Pages

| Fichier | Description |
|---|---|
| `index.html` | Accueil + globe 3D |
| `projects.html` | Liste et détail des projets |
| `submit-project.html` | Formulaire de soumission de projet |
